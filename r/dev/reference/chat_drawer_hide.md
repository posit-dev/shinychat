# Hide a chat drawer

Hide a chat drawer

## Usage

``` r
chat_drawer_hide(id, session = shiny::getDefaultReactiveDomain())
```

## Arguments

- id:

  The ID of the chat element.

- session:

  The Shiny session object.

## Value

Invisibly, `NULL`.
